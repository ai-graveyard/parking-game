# 1.2.0 发布前审查 · 2026-10-26

本次重新审查当前 `src/` 的运行逻辑、容器兼容、输入事件与打包边界，在原有修复基础上确认并修复两处 P2 输入问题。此次复审由单个代理完成；历史修复继续记录在下表。已重新生成 1.2.0 待上传 ZIP，尚未上传或发布。没有使用 Android / iOS 设备。

## 已修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| P1：临时 10 秒压车预览仍在生产源码 | 所有关卡时长变为 10 秒，超时跳过分享续时 | 删除预览开关及分支，恢复关卡和难度配置；回归校验每关时长；发布校验禁止预览入口 |
| P1：平台存档读取失败后可能覆盖旧成绩 | 一个键失败会跳过后续读取，新成绩可能覆盖未读到的原生成绩 | 每个键独立加载；保存前确认已成功读取，失败则重试并合并；读取失败或坏 JSON 不覆盖；合并自由挑战最佳纪录 |
| P1：驾驶控件和弹层依赖较新 CSS | Chrome / WebView 61 会丢弃部分尺寸和定位声明 | 补齐四边定位、尺寸、字体、Grid 间距回退；Flex 间距使用 margin |
| P2：顶部按钮避让依赖固定位置 | 容器安全区与按钮位置变化可能遮挡 HUD | 支持注入安全区变量；9.49+ 检测并读取 getWindowInfo，按原生矩形避让；旧客户端和调用失败保留 CSS 回退 |
| P2：方向盘未处理捕获意外丢失（本次复审） | 触点失去捕获后仍保留旧指针及转向值，方向盘不自动回正；额外手指可抢走正在操作的方向盘 | 统一处理 pointerup / pointercancel / lostpointercapture；同一时间由一个触点控制方向盘 |
| P2：踏板缺少触点归属（本次复审） | 同一踏板的第二根手指松开或丢失捕获，会中断第一根手指仍在进行的按压 | 每个踏板独立记录触点，只由该触点释放；暂停后的旧触点事件不会清除新按压 |

平台接口已对照本次读取的[小红书在线文档](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)。Storage 最低版本 9.46，窗口信息最低版本 9.49，振动最低版本 9.50，关注最低版本 9.51；调用均有能力检测和失败处理。未添加 AI、定位或陀螺仪功能。
