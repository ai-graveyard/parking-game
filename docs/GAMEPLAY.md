# 玩法说明

当前开发版本提供 16 关固定主线和随机自由挑战。游戏离线运行，采用方向盘和「前进 / 后退」按钮的双指操作。

## 16 关主线

12 个普通关直接开放，04 / 08 / 12 / 16 是可选的关注福利关。小红书 9.51+ 且关注接口可用时，未关注玩家可以预览福利关，主动点击后发起关注，一次成功解锁四关；下一关推荐跳过尚未解锁的福利关，不阻断普通课程。自由挑战全部开放。

已关注和作者本人直接显示普通关卡，不显示关注锁或弹窗。启动查询期间显示中性确认状态；查询失败提供重试并保持其他课程可玩。确认解锁的权益保存在本地，不因后续取消关注而收回；历史已通关的福利关不重新加锁。普通浏览器和不支持关注接口的旧客户端开放全部关卡。`ALL_LEVELS_OPEN` 仅控制普通课程是否要求前置进度，不绕过关注福利判断。

## 三种车辆

所有数值为游戏场地单位，并非真实车辆规格。场地按同一个 390 × 350 世界等比投影，车辆和障碍物保持相同相对尺寸；手机尺寸变化不会改变转弯半径与地图内容。

| 轴距占车长 | 58% | 67% | 73% |
| 最大轮胎转角 | 0.64 弧度 | 0.59 弧度 | 0.56 弧度 |

车辆使用带后轴偏移的自行车转向模型。货车转向响应更缓，车头与车尾都会摆动；大卡车是车头车厢一体的厢式车。未来轮迹与驾驶使用同一套模型，反映当前轮胎转角。货车有独立的驾驶室、货箱和车轴绘制。邻车按停车区匹配同类车型：轿车旁停轿车，小货车旁停小货车，大卡车旁停大卡车。大卡车车位至少长 140、宽 68 世界单位：128×40 的车身倾斜 10° 时占约 133×62，另预留每侧 1 单位的入框安全边距与 2 单位的位置偏差。主线第 13、14 关车位为 154×68，第 15 关为 164×68；第 16 关原有 154×69.2 已满足要求。自由挑战在难度缩放后仍保留上述最小余量；邻车车位与间距同步适配，不能靠放宽碰撞或允许车身越线来完成停车。

## 车位标线与车型分区

场景统一采用新粗野主义驾校训练场外观：纸黄色网点背景、灰色网格地面、粗墨线围边和偏移硬阴影，黄黑交替路沿。网点由可复用的 14×14 Canvas 图案绘制。场地按科目标注倒库、侧方或模拟装卸训练区；上沿不足以放置标识时，名称移至下沿，避开长车和隔离设施。出生点后方在空间足够时绘制起步线与「起点」地面字。训练隔墙采用砖红色错缝砌砖，两排砖块搭配浅色砂浆缝、轻微深浅交替和深色侧边，横竖墙体均沿长边铺砖；采用俯视图，保留粗黑描边与偏移硬阴影。相接墙段按矩形并集生成连续外轮廓，仅绘制整体描边与阴影；死胡同、仓库等 U 形围墙的顶部和转角不再出现内部黑边或重叠阴影。横竖墙相接的上转角采用两排错开的 L 形转角砖，砖缝沿转角延续并对齐两侧墙面的原有砂浆缝；转角长砖的两臂再用错开的短砖缝切分，并交替砖红色深浅，避免整角像一块大砖。死胡同左侧收窄处补上与碰撞一致的转角连接段。仓库卸货口横墙与普通墙体共用上述俯视砖墙绘制；独立立柱保留橙红、明黄色块与黑色斜纹。花坛采用小圆角暖色围边、浅棕底色、成片交叠的双色尖叶与放大的圆瓣雏菊花形，统一黑色轮廓、鲜明色块和硬阴影，去掉砖缝；叶片采用两端收尖的曲线轮廓和单条叶脉，成对朝不同方向舒展；花朵采用六瓣或八瓣椭圆花瓣、清楚的圆形花蕊，搭配粉色、奶油白和金黄色。大花坛八簇叶丛配六朵花，小花坛四簇叶丛配两朵花；按固定错落位置、大小与倾角绘制，植物裁剪在圆角内沿中。

新增地面纹理、起步线和分区字均是环境绘制；上沿不再摆放左右对称的路锥。场地左右及下沿空处有少量可碰撞的雪糕桶，按场地种子随机选择数量及轻微位置偏移，避让车位、起步区域、检查区、出口和已有障碍；重试及窗口变化保持原位置。车位内部不绘制方向三角，任务提示维持轻量样式。

三种车辆统一使用简洁的俯视插画 PNG：平滑圆角、粗黑边、薄荷色前风挡与大色块。小货车货箱去掉细筋和五金，驾驶室去掉凹槽；大卡车篷布保留三条粗绑带与两道大明暗，去掉密集褶皱、扣件、凸台和轮胎纹路。玩家车辆、同类邻车及黄色目标位预览沿用同车型造型，手机小尺寸以轮廓、车头和货厢识别车型。两种货车的后缘采用平直方尾和小圆角，尾灯是竖直小矩形，驾驶室保留圆润轮廓；所有配色一致。三种车型的后视镜均为贴近前舱的小短镜，镜壳及描边不超过轮胎最外沿；玩家、邻车和目标预览一致。

三种车辆都按实际车身边界校准，后视镜、轮胎和透明留白不参与车身尺寸的定位，绘制共用单一等比缩放系数。每款配色有独立定位框，可见车身约为小轿车46×22～23、小货车80×33.1、大卡车128×36.8。对应碰撞范围是46×24、80×34、128×40。大卡车加长货厢，车长为小货车1.6倍、轿车约2.8倍；轴距比例不变，转弯半径随真实车长增加。四套卡车配色同步加长。

玩家和目标位预览使用橙红小轿车、橙白小货车或蓝头绿篷大卡车。同区轿车邻车混合蓝、鼠尾草绿、奶油黄、浅紫四种车漆；小货车邻车有蓝、绿、紫驾驶室配浅色货箱；大卡车邻车有珊瑚红头配沙色篷、绿头配奶油篷、芥黄头配灰蓝篷。配色随场地种子和邻车序号确定，不消耗几何随机数，重试、暂停和窗口变化不会换色。

小轿车后窗使用较深的烟熏蓝绿色；考虑实际小尺寸，两侧玻璃简化为连续的深色凹陷阴影，去掉窗格、窗柱和碎高光。前风挡保留浅色玻璃和高光，方便识别车头方向。

玩家车辆通过车外的浅珊瑚橙实心小箭头标识，车顶不再覆盖「你」字。开场显示 3 秒，一旦开始行驶立即隐藏；之后连续停稳满 3 秒才再次显示，重新行驶就隐藏。箭头显示时每约 3.6 秒轻轻上下浮动一次，单次约 0.8 秒、最大位移约 3 个缩放像素；尊重系统减少动态效果设置。暂停不累计停留或浮动时间，暂停、结算和车辆被碾碎时不显示；重新挑战及教学结束重新触发开场提示。

箭头跟随车辆位置，保持指向车身；车辆靠近场地上沿时改放到下方，旋转时也留在车身外。三种车型使用相同规则，邻车不显示此箭头；目标位保留原来的黄色指示。

目标车位、邻车车位、院内泊位和仓库装卸位均绘制对应的地面白线；倒库和斜列位的开口朝向行驶区，侧方位使用矩形边线。目标位采用淡黄色填色、细虚线和静止小箭头，入位后转为淡绿。标线仅用于指引，不参与碰撞。

任务说明只在顶部轻提示条显示，开场不再重复弹条，车位上方也不再重复绘制说明文字。行驶中的状态缩短为「前进中」「倒车中」，入位后按需提示摆正/停稳。玩家箭头、预测轮迹和新手教学的描边、明暗及动效减弱；碰撞、阶段切换、完成和倒计时紧急反馈保留。

正式倒计时消耗超过本关限时的一半（含碰撞罚时），且车身仍未接触黄色车位时，顶部原有任务条自动显示一句当前步骤的建议，5 秒后恢复任务文字；黄色车位加强描边 2.5 秒后淡出。提示出现时同步播放约 0.3 秒的轻柔上扬提示音，由 Web Audio 本地合成，遵守静音开关，每次提示只播放一次；音频不可用时照常显示提示。每局最多自动提醒一次，重新挑战后可再次触发。没有提示按钮、弹出卡片或遮罩，不改变场地布局。教学和暂停不消耗提示等待时间。车身任意部分进入车位，或暂停、救场、结算及任务阶段变化时清除当前提示，继续本局不会重复提醒；停好后驶向出口的阶段不再提示。

每辆邻车使用其真实车型、车长和车宽绘制与碰撞检测，停在独立标线范围内。普通停车行按行排列；加长卡车的侧方位保留一辆完整邻车，另一端设置护栏，所有车辆和标线完整落在场内。倒库车位根据加长后的长度下移，绕柱起点及随机倒库起点保留足够转向空间。院墙和检查区附近按实际空间布置同类邻车，保留转弯与任务通道。

## 随机自由挑战

三种车辆均可直接选择，无需先通主线。每种车可选择倒库 / 侧方、简单 / 困难 / 地狱，共 18 组独立纪录。

基础限时为 100 / 60 / 30 秒，小货车乘 1.35、大卡车乘 1.8 后四舍五入。自由挑战的三星目标为限时的 48%（四舍五入）。不同车型采用各自尺寸与转向模型。

每局用种子生成：目标位横向偏移、出生位置、左右镜像和边缘路障会变化；高难度倒库增加花坛或立柱，侧方缩短车位。重开换种子，窗口变化保留种子。随机变化有边界，主行驶空间和目标附近不随意塞满障碍物。

## 操作与停车判定

- 所有游戏内弹框均提供右上角关闭按钮。暂停框关闭即恢复当前驾驶；选关、救场和结算框关闭后显示当前现场与返回入口，分别保留未开始、等待救场和已结束状态。收起救场既不接受失败也不扣续时，反复打开结算不重复计游玩次数或通关。分享／关注请求待回调时，父弹框关闭按钮暂不可用；本地模拟确认框的关闭等同取消。横屏提示收起后仍禁止开始、重开及恢复驾驶，转回竖屏后再操作。
- 左手沿圆周转动方向盘，左右各可打一整圈；松手自动回正。
- 按住「前进」向前行驶；前进时按住「后退」会先刹车，停下后继续向后行驶。松开按钮逐渐减速停稳。桌面支持方向键。
- 首次游玩有可跳过的三步教学，教学期间不计时、不罚时。
- 每次打开页面进入训练时，方向盘和踏板各有一个半透明白色手势引导，文字明确左/右拇指用法：左侧沿轮缘小幅转动，右侧演示按住踏板。操作过某一侧后该侧立即消失，本次页面访问内重试不再出现；暂停和结果隐藏，恢复时只显示尚未使用侧。键盘方向键也会消除对应侧提示。动效遵循减少动态效果偏好，虚影不拦截触控。
- 车位内的淡色车辆预览表示最终车头方向。每个停车目标只有一个正确车头方向，绿色出口同样检查朝向。整车进入、朝向误差小于 10°（正好 10° 不通过）、速度低于停稳阈值并连续保持 0.65 秒，即完成停车；任一条件失效立即清零停稳进度。
- 车身中心进入目标区域且车头朝反方向时，任务栏持续显示「方向反了」和应朝方向，并弹出一次驶出调头提醒；纠正或离开后清除提醒，再次停反会重新提示。
- 倒库与侧方均要求倒退进入：车辆首次与车位相交时，需要正在倒车且车尾朝向车位中心。车头开入再在框内倒一下不会通过；需要驶出后重新倒入。
- 正面撞击扣 2 秒；剐蹭掉速、不罚时。两者均影响星级。
- 碰撞反馈出现在实际接触边缘：撞击有 12 条火花和双色冲击弧，剐蹭有 8 条更轻的火花，约 0.38 秒内消退。火花带细暖色外沿，提高地面和护栏上的对比度。回弹使用更小的法线冲量和更快衰减，反向车速最高为 8 世界单位/秒；位移必须通过场地碰撞检测，窄处不能穿过另一侧障碍。剐蹭时车身沿接触法线短促抖动，振幅上限约 1.3 世界单位并快速衰减，仅作用于绘制，不改变驾驶位置或碰撞框。无实际位移的轴向退让不再误记为剐蹭。
- 撞击播放低频闷响，剐蹭播放短摩擦声；音量随接触速度调整。音效由 Web Audio 本地合成并复用短噪声缓冲，受声音开关控制；能力不可用时不影响驾驶。撞击 / 剐蹭分别保留 0.7 / 0.55 秒冷却，避免持续贴墙反复刷反馈。
- 倒计时归零时先检查每日救场机会；放弃、无可用机会或续时再次耗尽后，车辆立即停下，播放约 5.39 秒的巨型黑铁秤砣动画（含 85 毫秒命中停顿）。秤砣从上方加速砸向玩家车，0.58 秒处触发冲击圈、短促震屏和平台重振动，并播放本地合成的低频重击、脆响及低沉铁块余音。铁块保持刚性，压住后抬起，露出车身褶皱、轮胎翻平的薄片车，再轻微回弹定住；小轿车、小货车和大卡车各用对应的压扁素材，保留车窗、车头／货厢与原配色，大卡车保留六个轮胎。秤砣按车型和朝向调整大小，画面裁剪在驾驶区内；邻车、障碍物和地图不变。抬起后显示「考核不通过 · 这下，真·平了。」，再打开结算。减少动态效果时显示静态压扁车和失败印记，不显示移动秤砣与震屏；静音时不播放音效。失败分享图保留压扁现场，重试及救场恢复原车。备用坦克不进入普通失败与分享流程。

## 每日首次分享续时

- 「考核不通过」文字完整出现并稳定后，压扁现场再保留 3 秒才打开结算弹窗。减少动态效果模式也保留 3 秒；切到后台或横屏拦截时暂停这段等待，重试会清除旧流程。

- 主线和自由挑战共用每天一次续时，北京时间零点刷新。原始限时不足 90 秒加 5 秒，90 秒及以上加 10 秒，按车型调整后的原始限时判断。未用完的机会不跨天累积。
- 当天首次符合条件的超时暂停现场，玩家可分享笔记或接受失败。拒绝后，当天不重复自动弹窗；失败结算仍保留手动救场入口。普通浏览器或缺少 `postNote` 时保留原有超时失败流程。
- 原生 `postNote` 成功回调后才获得待用机会，取消和失败不发奖、不扣机会；没有按时间推测成功的逻辑。回调只代表用户点击发布，不代表审核通过。
- 玩家也可先在通关或失败结算页分享，提前获得当日待用机会。分享与使用分开：返回后再次主动点击使用，经过 3 秒准备后恢复驾驶。后台、横屏拦截期间准备计时暂停。
- 救场保留超时前车辆位置、朝向、场地种子、任务阶段和碰撞记录，并清空按住的踏板及方向盘输入；结算后救场会还原超时现场并清除压扁状态和失败印记。保存的归一化位置适应窗口尺寸变化。
- 每局最多续时一次，用完后再次超时由巨型秤砣重砸后结算。同一局失败结算后救场再通关，只计一次游玩次数。
- 续时不提高三星目标，不减少真实累计用时或碰撞。结算与战绩图标注「使用续时」。救场笔记使用当前现场和「挑战中」，不虚构通关或全国排名。
- 本地状态键为 `parking-game.growth.v1`。存储失败提示后仍允许本次游玩，数据被清理后无法保证权益和每日额度保留；此离线方案不提供账号跨设备同步或服务端防刷。

## 星级、记录与分享

- 分享图保持 720×960（3:4）；停车场景按原始比例完整缩放、居中留边，车辆、车位和失败印记不会被拉宽或压扁。战绩图按成功／失败所需文字行数分配场景高度，收紧点评与成绩栏之间的留白；续时分享图使用同样的等比规则。

- 一星：完成全部任务。
- 二星：完成任务，零撞击、零剐蹭。
- 三星：零撞击、零剐蹭，同时达到本关目标时间。

主线按关卡记录最快净用时、最高星级、通关次数、游玩次数；自由挑战按「车型 + 科目 + 难度」记录。新版保留旧版小轿车六组成绩作为自由挑战的兼容展示，主线从第一关开始。

满足客户端版本条件时使用小工具 `getStorage` / `setStorage`，普通浏览器或旧客户端使用带异常处理的 `localStorage`。读取原有浏览器进度后迁移到平台缓存；保存失败会提示，本次游玩仍可继续。碰撞与通关反馈在支持的客户端使用 `vibrateShort`。

结算提供原场地重试、下一关与战绩分享。分享图和文案标明具体关卡或车型 / 科目 / 难度。主线全通后可进入自由挑战，或重刷 48 星。不再向用户显示没有后端依据的全国百分位。

## 本地模拟预览

运行 `npm run dev` 后访问 `http://127.0.0.1:4173/?simulate=1`。右下角面板可切换未关注 / 已关注、立即超时、重置今日额度。默认未关注，福利关可预览但需通过模拟关注确认页解锁。分享显示当前笔记图片和正文，提供模拟发布成功、取消、失败；发布成功后继续走游戏本身的待用机会、主动使用、3 秒准备及 5 / 10 秒续时流程。

模拟存档键有独立前缀 `parking-game.local-simulation.v1.`，刷新保留且不读取普通试玩进度。模拟模式下切换未关注会重置四个福利关的模拟权益与成绩，以恢复锁定；每日额度重置返回选关并开启新局，不绕过每局一次规则。面板可收起，点击「退出模拟模式」返回普通浏览器体验。

模拟 SDK、面板和控制钩子由本地 Python 开发服务按 `simulate=1` 参数注入；生产 HTML / JS 无模拟代码，打包清单不包含开发服务或模拟脚本。开发服务仅监听 127.0.0.1。已有真实 SDK 时不覆盖它。`scripts/test-local-preview.cjs` 在浏览器里实点模拟面板验证流程，并检查普通存档隔离及生产文件边界。

## 开发验证

```sh
npm run check
npm test
```

`check` 校验运行资源、全部 JS 语法、DOM 引用、容器能力与离线资源约束。

`test-game.cjs` 在隔离 VM 中验证 16 关 × 三种屏幕、720 个随机布局的出生 / 目标位置、真实倒车入口判定、分阶段任务、星级、解锁、记录和驾驶参数。`test-growth.cjs` 使用模拟原生接口检查关注状态、关注取消/失败/频控、历史通关权益、分享取消重试、每日额度、北京时间跨天、结算后救场、任务阶段和真实成绩。`solve-missions.cjs` 使用同一车辆转向模型搜索连续无碰撞路线，并回放检查倒车入口；它验证几何可达性，不代替真人操作验收。测试钩子只存在于隔离测试环境，运行游戏不提供解锁或瞬移入口。

平台模拟器、Android 和 iOS 真机仍需在准备发布的同一 ZIP 上另行验收。本地浏览器验证不等同于小红书容器验收。

关卡和车辆配置集中在 `src/challenges.js`，布局、流程、记录和绘制位于 `src/app.js`。本次为本地开发预览，未发布。
