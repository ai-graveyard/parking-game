# 多手机尺寸布局复查

日期：2026-10-26。检查当前源码与本地多屏工作台；使用 Codex 内置浏览器截图、逐屏 DOM 测量和实际按钮操作。

尺寸：320×568、375×667、360×800、390×844、412×915、430×932。安全区配置分别为顶部 / 底部 0 / 0、44 / 34、59 / 34 CSS 像素。

## 1. 驾驶画面：已修正并复查

- 320 宽度的速度表与“右手 · 速度”有约 10px 横向重叠；小屏速度表缩窄后保留文字间距。
- 手势提示原本覆盖后退按钮底部；提示移至控件下方的独立留白区。
- 底部安全区原本消耗控件高度；现在增加操作区总高度，保持踏板可用高度，场地投影同步使用实际操作区高度。
- 375×667 的方向盘原本会伸出触控区并碰到下方提示；短屏改用 100px 圆形方向盘。
- 小屏副标题与任务行增加间距，计时数字适当缩小。
- 六种尺寸 × 三种安全区共 18 组，速度文字、踏板、方向盘和提示未发现重叠，踏板高度至少 51px；16 个关卡 × 六屏顶部布局均通过测量。

![修正后的六屏驾驶画面](../dist/qa/responsive-audit/07-driving-final.png)

## 2. 选关：已修正并复查

375×667 在顶部 59px / 底部 34px 安全区下，开始按钮原本进入底部安全区；将两列紧凑关卡布局扩展至 720px 及以下高度，并保留原生安全区偏移。18 组尺寸 / 安全区组合的开始按钮及关闭按钮均完整可见。

![六屏选关](../dist/qa/responsive-audit/05-select-after.png)

## 3. 暂停：通过

六种尺寸、顶部 59px / 底部 34px 配置下，暂停卡片、关闭、继续、重开及选关按钮均在可用区域内。另实际点击小屏的暂停及继续按钮，流程正常。

![六屏暂停](../dist/qa/responsive-audit/06-pause-after.png)

## 4. 预览工作台：已修正并复查

六屏时原来的最小列宽会裁掉最右侧屏幕；现在五至六屏在桌面下分为三列并自动换行。实测工作台横向内容宽度与容器一致，没有水平裁切。截图使用固定 45% 比例，避免全页截图改变视口高度、触发自动缩放而影响证据。

## 验证与边界

后续长屏调整：将顶部信息、场地和驾驶区收拢为一组，按场地比例计算剩余高度，均分至整组上方和下方。场地与驾驶区之间只保留约 6px 间距；场地比例及位置保持稳定。六种尺寸 × 三种安全区的浏览器复查，以及 16 个关卡的布局回归与完整游戏测试通过。根据后续要求，顶部主标题改为所有尺寸均显示；与中间按钮的间距不足 8px 时，标题及副标题整体下移，任务和场地同步避让。
