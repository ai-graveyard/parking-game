# 会停车吗你

<img src="docs/assets/branding/logo-final.png" alt="会停车吗你图标" width="200" />

发布素材：[方形 Logo](docs/assets/branding/logo-final.png) · [3:4 封面](docs/assets/branding/cover-3x4-v3.jpg)

一个为手机竖屏设计的零依赖停车网页小游戏，适配小红书离线小工具。当前版本 **1.2.0** 提供 **16 关主线 + 随机自由挑战**：从小轿车倒库，到小货车送货、大卡车进场。每天首次分享笔记可获得一次 5 / 10 秒救场续时，超时放弃或机会用尽后，巨型黑铁秤砣砸下，把玩家车压成车身褶皱、轮胎翻平的「汽车饼」，配重砸停顿、轻微回弹和低沉重击音效，再以「考核不通过」结算。

项目只使用原生 HTML、CSS 和 JavaScript，不联网、不收集数据，也没有运行时依赖。除普通浏览器外，源码同时兼容小红书离线小工具容器。

## 开始运行

需要 Node.js 18+ 和 Python 3。

```bash
npm run dev
```

浏览器打开 <http://127.0.0.1:4173>。如果需要更换端口：

```bash
PORT=8080 npm run dev
```

本地可打开 <http://127.0.0.1:4173/?simulate=1> 进入模拟模式；普通预览页右下角也提供「开启本地模拟」。模拟面板支持预览未关注 / 已关注、立即超时、重置今日额度。点击关注或分享后会显示模拟确认页，可选择成功、取消或失败；分享成功后再手动使用续时，即可体验完整流程。

模拟状态使用独立存档，刷新保留，不影响普通试玩记录；「预览未关注」会清除模拟福利关权益及这四关的模拟成绩，方便重新查看锁定效果。重置今日额度同时返回选关，开始新的一局。模拟脚本及游戏控制入口由 `scripts/preview_server.py` 仅在本地响应中注入，不写入 `src/`，不会进入上传 ZIP。模拟模式不会执行真实关注或发布笔记，也不能代替平台验收。

桌面端可用方向键测试，手机端支持方向盘和踏板双指同时触控。

多手机尺寸同时预览：运行开发服务后打开 <http://127.0.0.1:4173/preview>。可选 320×568 至 430×932 的六种视口，并排比较同一关卡的选关、驾驶及暂停画面；支持统一刷新、缩放与模拟顶部 / 底部安全区。选择「通关分享图 / 失败分享图」可直接调用当前生成器，对比各视口导出的 720×960 PNG 并下载原图；分享卡上半部按导出分辨率重新绘制完整场地，不受通关镜头放大影响，保留原版黑底游戏名、关卡色块、大称号、星级、教练点评和虚线成绩框，补充车型，文字按宽度调整字号；使用模拟成绩，不会发布或写入通关记录。各屏可独立操作，预览存档按屏幕隔离，默认静音。工作台与模拟入口均保留在 `scripts/`，不进入上传包。

## 校验与打包

```bash
npm run check
npm test
npm run package
```

`npm run check` 检查运行文件完整性、容器合规性（不联网、无内联脚本、无外部资源）、预览入口隔离和版本号一致性。打包脚本还需要系统安装 `zip` 和 `unzip`，产物会写入 `dist/parking-game-v<版本号>.zip`，ZIP 根目录直接包含 `index.html`，可用于静态托管或小红书小工具上传。

可选本地浏览器检查：先运行 `npm run dev`，使用已有的 Playwright 工具执行 `npm run test:browser`。通过 `PLAYWRIGHT_MODULE` 指定工具模块，必要时通过 `CHROMIUM_EXECUTABLE` 指定浏览器、`GAME_URL` 指定预览地址。截图统一写入已忽略的 `dist/qa/`，不会进入发布包。这些检查使用模拟 SDK，CSS 回退检查也运行在现代浏览器中，不构成真实旧内核或平台验收。

本次发布前审查、ZIP 校验和待测项目见 [发布审查](docs/RELEASE_REVIEW.md)；历史素材的归档与清理清单见 [素材清理记录](docs/ASSET_CLEANUP.md)。

## 项目结构

```text
parking-game/
├── src/                   # 唯一的游戏源码与运行资源，也是打包上传的内容
├── docs/
│   ├── GAMEPLAY.md        # 完整玩法与调参说明
│   └── assets/            # 图标与截图，不参与游戏运行
├── scripts/
│   ├── dev.sh             # 本地预览
│   ├── package.sh         # 生成离线 ZIP
│   ├── validate.mjs       # 容器合规与资源完整性检查
│   ├── test-game.cjs      # 玩法、进度、驾驶模型验证
│   └── solve-missions.cjs # 连续转向模型的关卡路线验证
├── VERSION                # 当前版本号，与 package.json 保持一致
└── package.json           # 无依赖的项目命令入口
```

项目只保留最新版本，游戏源码与运行素材统一放在 `src/`，说明文档放在 `docs/`。发布新版本时直接修改 `src/`，并同步更新 `VERSION` 与 `package.json`；不再创建或保留版本目录。

生成的 `dist/`、本地 AI 工具配置和系统文件不会提交到仓库。

## 游戏说明

- 主线四章：小车入门、进阶训练、货车训练、大车训练，每章四关。进阶四关包含窄斜列位、大花坛绕障、收窄巷口倒车及两阶段窄巷出库。
- 关卡包括倒库、侧方、斜列、窄门、死胡同、绕柱，以及停车后驶出、检查后卸货的分阶段任务。
- 三种车辆的车身、轴距、转弯半径、加减速和惯性不同，轨迹预览使用同一驾驶模型。
- 场景采用新粗野主义驾校训练场：纸黄网点背景、灰色网格地面、粗墨线与硬阴影、黄黑路沿、贴纸分区和起步线；目标位淡黄色标识，车位内无方向三角，货车旁停同类货车。
- 主线场地固定，12 个普通关直接开放；04 / 08 / 12 / 16 关注作者后一次解锁，已关注玩家看不到关注锁，普通课程推荐跳过福利关。普通浏览器和不支持接口的旧客户端开放全部关卡。自由挑战全部开放。
- 整车进位、朝指定方向摆正并停稳；每个停车目标（含绿色出口）只有一个正确朝向，停反会提醒。倒库和侧方都要求车尾先倒入。
- 正面撞击扣 2 秒，剐蹭只掉速；零碰撞可拿二星，同时达到目标时间获三星。
- 首次游玩有可跳过的三步教学，教学期间不计时也不罚时。
- 顶部三横杠可暂停并选关；点击开始所选关卡后，确认终止当前局才会切换。关闭选关或选择继续当前关卡，会恢复原位置和剩余时间，已有成绩保留。
- 选关、暂停、救场和结算弹框都有右上角关闭按钮：暂停关闭即继续，其他弹框收起后可查看现场并重新打开；收起救场不消耗机会，收起结算不重复记分。竖屏提示可收起，转回竖屏后再开始或继续驾驶。
- 每天首次分享笔记获得一次 5 / 10 秒续时，可在超时现场或失败结算后主动使用；取消不扣机会，北京时间零点刷新。
- 进度、关注权益、每日额度和成绩保存在本地；结算可分享战绩笔记，救场图明确标注挑战中。
- 当前为本地开发版本；平台模拟器及 Android / iOS 真机需在发布前另外验证。

更完整的规则、场地生成逻辑和调参位置见 [玩法说明](docs/GAMEPLAY.md)。
