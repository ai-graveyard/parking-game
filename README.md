# 会停车吗你

一个为手机竖屏设计的零依赖停车网页小游戏，发布在小红书小工具上。三个科目、三个难度，每局场地随机生成。

## 目录结构

按版本号分目录，每个目录都是一份可以整体打包上传的完整产物（小红书打包时不允许夹带 README，所以 README 只留在仓库根目录）。

- `1_0_0/`：已发布的 1.0.0 版本，作为存档不再改动。
- `1_1_0/`：正在开发的 1.1.0 版本。

## 科目与难度

三个科目共用同一套物理和碰撞，区别在车位的朝向和进入方式：

- **倒车入库**：车位开在路肩上方，垂直于道路，两侧有邻车。
- **侧方停车**：车位在路面靠路肩一侧，夹在前后两辆车之间，需要沿路方向摆正。
- **斜列车位**：车位与道路成约 40° 斜角，成排排列，需要斜着切进去。

三个难度控制限时、车位尺寸和路障数量：简单 100 秒（大车位、1 个路障），困难 60 秒（标准车位、4 个路障），地狱 30 秒（小车位、7 个路障）。通关后结算页会推荐下一难度；通关地狱后推荐下一个科目。

## 玩法

- 左手沿圆周转动方向盘控制转向，左右各可打一整圈（360°）。
- 朝下的方向盘支撑使用橙色区分，右上角的正负角度读数会同步显示当前方向盘位置。
- 右手按油门前进；按刹车减速，继续长按即可倒车。
- 右手控制区会实时显示当前时速（km/h）。
- 简单和困难难度会显示约一辆车身长的浅白色未来轮迹；地狱难度不显示轨迹预测。
- 车头采用圆滑鼻头和白色前灯；车尾采用方正造型和红色尾灯。
- 在倒计时内让整辆车进入黄色车位、摆正并停稳，车位上的橙色进度环表示还要稳住多久。
- 路肩以上除车位内部都当墙处理，只能从路面进入车位。
- 正面撞上车辆或路障扣 2 秒；沿着障碍物剐蹭只掉速、不罚时；两者都会记进结算明细。
- 倒计时归零后坦克会驶过并碾碎场景。
- 游戏中可暂停；暂停后可以继续、换一张场地重开或退出返回科目选择。
- 使用兼容 Android/iOS WebView 的 Web Audio 生成按钮声、倒车蜂鸣、最后 10 秒倒计时、坦克轰鸣和通关音阶。

## 场地生成

每局的场地由一个随机种子决定，屏幕尺寸只影响投影结果，所以中途改变窗口大小（比如手机地址栏收起）不会换掉正在挑战的场地。生成时会保证：

- 车位正前方留出一条走廊，路面下沿留出一条贯通的空车道，随机路障再密也一定有路开到车位前。
- 出生点不与车位、邻车或路障重叠，并且落在车位的另一侧。

## 记录与分享

每个「科目 + 难度」组合会在 `localStorage` 里记录最快净用时、最好星级和通关次数，开始页和结算页都会显示。结算按撞击次数和净用时评三星。结算页可以生成一张 3:4 的战绩图（长按保存），或复制一段战绩文案；如果所在 WebView 不支持导出图片，会自动降级成只复制文案。

## 本地预览

```bash
python3 -m http.server 4173 --directory 1_1_0
```

浏览器打开 `http://127.0.0.1:4173`。桌面端可使用方向键测试，手机端支持方向盘和踏板双指同时触控。把 `--directory` 换成 `1_0_0` 即可对照旧版本。

## 发布

版本目录内均为静态文件，可整体上传到支持 HTTPS 的静态托管服务。`index.html` 是入口文件，不依赖外部图片、字体或第三方脚本。`logo-square*` 是小红书上架用的封面图，不参与游戏运行。
